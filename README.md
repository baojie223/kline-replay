# K 线回放工作台 · Kline Replay

**面向本地浏览器环境的 K 线回放与手动 / 策略回测工作台**

## 核心特性

- **双标的回放工作台**：内置广发纳斯达克 100 ETF（`159941`）日线与郑商所甲醇期货（`MA`）分钟/日线行情，各自保留独立的模拟账户与历史回放存档。
- **期货多周期联动与画线标注**：甲醇手动回测支持 `1m` / `5m` / `15m` 周期切换与多图四宫格同步，点击 K 线可跨周期高亮对应时间范围；形成中的大周期 K 线仅使用已揭示行情，杜绝未来函数。支持在图上绘制线条与半透明方框标注并随场次保存。
- **图表画线挂单与拖拽止盈止损**：支持直接在 K 线上点选价格挂出限价单或突破单，成交后自动暂停并可从成交线上下拖拽设置止盈/止损；模拟盘内对手价偏移滑点与同根 K 线保守撮合顺序。
- **技术形态提示与均线开关**：提供一键开关 `EMA20`、Al Brooks 价格行为入场提示（H2 / 楔旗 / 楔底 / 区间）与 ICT 2022 入场提示（流动性扫荡 + 结构转换 + FVG 回踩）。
- **ETF 逆转策略与九档止盈对比**：逐根标记逆转信号、自动计算含双边佣金的净收益止盈价与止损价，并独立追踪 `1%` 至 `5%` 九档止盈目标的表现，支持导出逐笔成交与止盈对比 CSV。
- **甲醇 ICT 策略逐根动作回放与离线研究**：支持回放 5 分钟与日线 ICT 策略的每一笔信号、委托、撤单、开平仓与换月动作；`research/` 目录包含 2020–2026 年多周期、多策略及 EMA20 系统的可复算回测报告。
- **纯本地运行与完善的状态持久化**：行情在本地加载，多场次回放自动保存在浏览器 `localStorage`，支持逐根回退恢复当时账户与委托状态，并在多标签页并发编辑冲突时自动另存分支记录。

## 快速开始

建议使用 **Node.js 22.18+** 或 **24**（运行内置测试与研究脚本需要 `--experimental-strip-types` 支持）。

```bash
npm ci
npm run dev
```

打开终端输出的本地地址即可使用。其他常用命令：

```bash
npm test              # 运行核心撮合、策略识别与持久化单元测试
npm run build         # TypeScript 类型检查并构建生产包到 dist/
npm run preview       # 本地预览生产构建
npm run data:refresh  # 从东方财富更新 159941 最新不复权日线（可传 YYYY-MM-DD 截止日期）
```

> 说明：更新 `159941` 行情数据后，需重新运行 `npm run build` 以打包最新静态数据。

## 核心功能与撮合规则

### 图表交互与回放控制

- **快捷控制**：在 ETF 页面点击「新建回放」选择起始日期、初始资金和佣金。`Space` 播放或暂停，`←` / `→` 或工具栏按钮逐根回退与前进；点击「放大图表」进入专注视图，按 `Esc` 退出。
- **EMA20**：点击图内「EMA20」显示或隐藏 20 根 K 线的指数移动平均线。均线按图表当前周期的收盘价计算，甲醇换月后从新合约重新累计 20 根。
- **逐根回退与多标签页防冲突**：回退一根会暂停播放，完整恢复当时的账户资金、委托、策略进度、保护线与成交记录（已有回放从首次推进的位置开始记录快照）。两个标签页同时编辑同一轮回放时，检测到冲突的页面会自动另存一份进度，两份记录均可在「历史回放」中打开。

### 画线入场挂单与保护价编辑

- **画线入场挂单**：在甲醇手动回放右侧填写手数后点击「画线做多」或「画线做空」，或在 ETF 空仓时点击「画线买入」，直接在 K 线上点选价格挂单（光标旁显示实时价格与委托类型预览，也可在右侧输入精确价格，按 `Esc` 退出）。做多价低于现价提交限价单、高于现价提交突破单（做空相反），从下一根 K 线开始等待触价，跳空越价按开盘价模拟成交。拖动黄色挂单线可改价，点击「撤单」取消；甲醇换月或到达行情末尾时自动撤单。
- **拖拽设置与编辑保护价**：挂单触价成交后回放自动暂停，在蓝色成交线上按住拖动即可设保护价（多单上拖止盈、下拖止损，空单相反），从下一根 K 线开始撮合。在右侧也可预设市价单保护价；拖动横线或聚焦后用上下方向键微调，右侧可分别撤销止盈或止损。ETF 最小价位为 `0.001`，甲醇为 `1`，可将盈利持仓的止损移过开仓价保护利润。
- **保守撮合与对手价偏移**：已有保护价的委托在盘中触发入场时，同根 K 线优先判断止损，止盈还要求收盘价达到目标，以规避 OHLC 数据内部成交顺序的不确定性。手动保护单按触发方向模拟对手价偏移（如甲醇向上触及 `2000` 按 `1999` 成交、向下触及 `1000` 按 `1001` 成交），跳空开盘越价时同样基于开盘价偏移并限制在当根高低价之间；若因涨跌停或无成交量暂无法成交，则保留待执行状态等待下一根可成交 K 线开盘。

### 甲醇多周期手动回测

1. 在顶部「交易标的」选择「MA · 甲醇」进入手动回测，点击右上角「新建回放」选择起始交易日（休市日自动顺延）。内置 2025-11-17 至 2026-11-16 共 242 个交易日（含夜盘，夜盘按下一交易日归属，图上使用北京时间）。
2. 工具栏支持勾选 `1m`、`5m`、`15m`：单选铺满图表区，多选按四宫格排布（窄屏纵向排列）。每张图的「下一根」推进至该周期下一次收盘，所有图共用同一回放时钟；自动播放与键盘左右键按 5 分钟收盘推进或回退。点击任一图的 K 线，其他周期会同步定位并高亮对应时间范围（再次点击或「取消高亮」清除）。
3. **画线与方框标注**：使用工具栏「画线」或「方框」在同一张图上拖动或依次点击两点绘制，方框支持半透明填充与颜色切换，右击可删除；标注在各周期同步显示并按场次保存，回退到创建之前时自动隐藏。
4. **撮合与合约口径**：右侧普通市价委托以 5 分钟线为准在下一根可成交 K 线开盘撮合；画线挂单、止盈与止损按画线所在图表的周期撮合，仅使用未来完整 K 线价格。每手 10 吨、最小变动 1 元/吨，手续费按实际模拟成交额单边万分之 1 计算，成交表单独列出滑点（包含保护价触发后的对手价偏移）。每次管理一笔持仓、可隔夜，换月时按旧合约开盘价平仓并撤销旧委托，期末尝试按收盘价平仓（未纳入保证金及强平模型）。
5. **1 分钟行情对齐**：使用通达信 MAL8 原始行情，聚合后逐根核对 5 分钟开高低收与成交量（[1 分钟行情](research/ma-ict/market-1m.csv) · [郑商所甲醇业务细则](https://www.czce.com.cn/cn/uploadfile/2024/02/07/20240207154824122.pdf) · [行情来源与核对](research/ma-ict/REPORT.md#数据与核对)）。

### ETF 手动下单、逆转策略与九档止盈对比

- **手动下单与账户**：起始日及更早日线可见，每推进一步揭示一个交易日。买入时点可选「当天收盘」或「下一交易日开盘」（默认次日开盘，按 100 份整数倍、只做多）；可切换「固定价格」或「收益率」（1%–10%，默认 1%）设置止盈与止损，按计入双边佣金的平均成本计算触发价。默认单边佣金 `0.005%`（万 0.5），最低 `0` 元；一字涨跌停或无成交量按未成交处理，最大回撤按逐日收盘权益计算。
- **逆转策略**：看到认可的逆转时点点击「标记逆转」（当天为阳线则计入第 1 根，阴线或十字星保留计数），第 2 根阳线触发买入（可选信号日收盘或次日开盘，支持跨境 ETF [日内回转交易口径](https://investor.szse.cn/knowledge/stock/deal/t20171010_538497.html)）；买入后自动挂出扣费后净收益至少 `1%` 的止盈限价单与默认 `1%`（可设 `1%`–`10%`）止损单，可使用「快进到下一动作」跳转关键节点。
- **逐笔止盈对比**：每笔策略买入以相同入场价、份额、佣金和止损设置，独立追踪 `1%`、`1.5%`、`2%`、`2.5%`、`3%`、`3.5%`、`4%`、`4.5%` 和 `5%` 九档净收益目标，支持单独导出 CSV。

### Brooks 入场提示

基于 Al Brooks 价格行为学（市场周期、趋势与区间结构、信号 K 线与交易者方程，参考 [课程索引](https://www.brookstradingcourse.com/trade-price-action/) · [区间交易](https://www.brookstradingcourse.com/how-to-trade-manual/trading-ranges/) · [术语表](https://www.brookstradingcourse.com/price-action-trading-terms-glossary/) · [楔形读图示范](https://www.brookstradingcourse.com/trading-strategies/5-steps-to-finding-todays-trades/)）。打开图表下方「Brooks 入场」查看做多候选标记，悬停触发 K 线查看触发价、信号日与形态依据：

| 标记 | 本工具的识别条件 | 159941 样例触发日 |
| --- | --- | --- |
| H2 | 上行 EMA20 背景，两段回调后第二次上攻 | 2025-01-02 |
| 楔旗 | 上行背景里出现三个逐步降低的摆动低点，第三推后出现靠近最高价收盘的阳线 | 2026-11-11 |
| 楔底 | 下行背景里出现三个逐步降低的摆动低点，随后收盘突破第二、三推之间的反弹高点，回踩形成更高低点并出现多头信号 | 2026-04-23 |
| 区间 | 40 根日线内至少有四次交替的区间边缘测试，均线相对平坦。阳线测试下沿或跌破后收回，收盘在区间下三分之一且触发价在中线以下 | 2026-01-23 |

> 摆动点在右侧一根日线收盘后确认并按 ATR 过滤小幅波动，触发价取信号 K 线高点上方一档（¥0.001）。提示仅作为日线量化近似观察工具，微观结构与交易管理仍由复盘者结合图表判断。

### ICT 入场提示

点击图表下方「ICT 入场」即可在回放中叠加结构标注：K 线旁圆点表示 FVG 已确认并等待回踩，箭头与「ICT 多 / ICT 空」标记入场，K 线内圆点标出模拟成交价，悬停可查看扫荡价位、结构转换日期、FVG 区间、参考止损与 2R 目标（ETF 账户仍由原有下单控件操作）。

- **快速观察样例**：在 `159941` 中以 `2026-05-22` 新建回放，推进至 `2026-05-25` 可观察多头 FVG 确认，`2026-05-26` 触发 `¥1.621` 回踩入场；`2026-05-19` 与 `2026-05-20` 可观察一组空头形态。
- **规则参考**：取自 ICT 2022 课程的流动性扫荡、市场结构转换（MSS）与 FVG 回踩（[第 3 集](https://www.youtube.com/watch?v=nQfHZ2DEJ8c) · [第 6 集](https://www.youtube.com/watch?v=Bkt8B3kLATQ)），并与甲醇回测共用同一信号模块（详见 [甲醇 ICT 回测报告](research/ma-ict/REPORT.md)）。
